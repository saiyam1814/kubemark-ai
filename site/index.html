How It Works

1 · Pick your axes

NCCL collectives (all-reduce, all-gather, reduce-scatter, all-to-all, send-recv), NeMo/GPT-2 training throughput, or decomposed GPU cold-start (nvidia-smi → CUDA init → first kernel).

2 · Pick your isolation

Any RuntimeClass — gVisor, Kata, vNode — via --runtime-class, optionally inside an ephemeral vCluster per run with --vcluster. One flag each.

3 · Compare

compare-runtimes.sh runs the matrix, aggregates medians, computes overhead vs baseline, and renders everything in a local dashboard with charts.

Methodology, Honestly

What we control

Same machine type and GPU per comparison · repeated runs with medians · warmup runs identified and excluded · exit codes propagated so failures can't masquerade as results · results parsed from raw logs kept alongside every summary.

What we tell you anyway

Zone asymmetry between node pools · single-GPU scale limits · TCP vs RDMA path differences · which numbers are noise. Every caveat ships with the result — see the runtime benchmarking guide.
